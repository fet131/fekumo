# fekumo

> "An app that can create animated manga and also assist you."

Fekumo is an AI-powered manga assistant currently under active development. It gets better every day as it learns new creative workflows to support storytellers.

## What Fekumo can help with

- Brainstorming story ideas and arcs
- Writing scene drafts and scripts
- Designing characters and concepts
- Planning and animating manga panels

Think of Fekumo as your co-creator for building amazing manga stories from concept to motion.
